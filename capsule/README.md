# Same Transactions, Different Alarms — reproducibility capsule

**Journal:** *Discover Artificial Intelligence* (Springer Nature)  
**Paper:** *The choice of foundation model determines the false-positive burden of large language model anti-money-laundering transaction screening.*  
**Authors:** Samir Chincholikar; Robin Chawla (corresponding)  
**Code Ocean DOI:** https://doi.org/10.24433/CO.4804007 (this build supersedes v1; mint a new version on re-upload)  
**GitHub:** https://github.com/samirrc2/same-transactions-different-alarms

This capsule reproduces **every quantitative claim in the paper** from the frozen
data, offline, deterministically, at zero cost. The one-click **Reproducible Run**
(`/code/run`) verifies data integrity, runs the full analysis, and confirms the
outputs are byte-identical across two independent runs.

---

## What the Reproducible Run does

Running `code/run` (Code Ocean) or `bash reproduce.sh` (locally):

1. **Verifies data integrity.** Regenerates the 600-case battery from its fixed
   seed and confirms its SHA-256 matches the shipped file and the manifest; confirms
   every one of the 10 capture CSVs matches its freeze-receipt SHA-256.
2. **Runs the analysis** (pure, seeded, no network):
   - per-model false-positive rates on the 300 legitimate cases, with Wilson and
     cluster-bootstrap (2,000 draws) 95% confidence intervals;
   - the false-positive **spread** and cross-model **disagreement**;
   - the paired inferential tests the design licenses — **Cochran's Q** for the
     overall difference and **McNemar's exact** test (Bonferroni-corrected over the
     10 model pairs);
   - per-model **classification metrics** (precision, recall, specificity, F1,
     balanced accuracy, MCC);
   - per-typology miss rates (the trade-based blind spot) and prompt-variant flip;
   - two non-LLM **baselines** (FATF rules heuristic; supervised classifier, 5-fold
     out-of-fold) on the same battery;
   - the operational **alert-volume projection** at 0.1% prevalence.
3. **Checks reproducibility.** Re-runs the whole analysis in a second, isolated
   output directory and confirms the SHA-256 of every result file is identical.

**Outputs (written to `results/`):** `metrics_summary.md`, `pivot_claims.json`
(every number with its CI and the config hash), `classification_metrics.{json,csv}`,
`stats_tests.json` (Cochran's Q + McNemar), `baselines.json`, `alert_volume.json`,
`prompt_sensitivity.{json,csv}`, `table1_operating_points.{csv,md}`,
`table2_alert_volume.{csv,md}`, `data_integrity.json`, `output_hashes.json`,
`replication_check.md` (the PASS/FAIL audit), and `figures/fig1–fig7.pdf` (the
paper's display items, derived from the reproduced numbers; shipped as static
artifacts and excluded from the byte-identical check).

## Run it

**Code Ocean:** open https://doi.org/10.24433/CO.4804007 and press **Reproducible Run** (`/code/run`).

**Locally:**
```bash
pip install -r code/requirements.txt
bash reproduce.sh                 # verify + analyze + reproducibility check
# or:
bash reproduce.sh --analyze-only  # skip the second-run byte check
```
No API keys, no network, no cost.

## Repository layout

```
code/
  run                     Code Ocean entry point -> code/scripts/reproduce.sh
  scripts/reproduce.sh    path detection, env setup, runs the analysis + check
  src/                    analysis
  capture/                DATA-COLLECTION harness (reference only; NOT run here)
  requirements.txt        pinned offline-analysis dependencies
  tests/                  pytest sanity checks on the reproduced numbers
data/
  battery/                frozen 600-case battery + pilot subset
  capture/                10 frozen capture CSVs (5 models x 2 prompt variants)
  frozen/                 freeze receipts (SHA-256 of each capture CSV)
  configs/                models.yaml, grid.yaml, battery.yaml
  manifest/               battery_manifest.json
  README.md               data provenance + schema
environment/Dockerfile    pinned reproducible environment
metadata/metadata.yml     capsule metadata
docs/                     preregistration, amendment, decisions, data-collection note
results/                  analysis outputs (regenerated by the run)
  figures/                fig1–fig7.pdf (paper display items; static, see note above)
```

## Scope of reproduction (important)

- **Capture** (live vendor APIs) is **not** re-run here; frozen CSVs are hash-verified.
- **Analysis** reads only frozen inputs and is byte-identical on re-run.
